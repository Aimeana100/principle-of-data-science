Marking scheme
  • Foundational = 1 mark, Intermediate = 2 marks, Advanced = 3 marks (Set A = 125 marks, Set B = 83 marks).
  • Set A (Q1–60) mixes theory with calculations; Set B (Q61–100) is calculation-free and tests principles, technique choice, data cleaning and validation.
  • Multiple choice, true/false and numerical questions are auto-marked. Numerical answers accept a stated tolerance.
  • Multiple-select earns partial credit: (correct ticks − wrong ticks) ÷ number of correct options, never below zero.
  • Short-answer and written scenario questions are self-marked against the examiner's rubric: tick each point your answer covers.
